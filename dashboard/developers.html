Create a payment using the Edgipay REST API
curl -X POST https://api.edgipay.com/v1/payments \
  -H "Authorization: Bearer $EDGIPAY_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "amount": 25000, "currency": "UGX", "method": "mobile_money" }'
